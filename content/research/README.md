# MemoryBench Research Archive

This directory is the GitHub-readable research corpus for MemoryBench.

The website reads generated metadata from `src/data/researchDigest.json`, while
the human-readable source of record stays here as Markdown.

## Structure

- `articles/`: durable essays, category briefs, benchmark notes, and editorial research.
- `daily/`: scheduled research-watch digests generated by the automation.
- `sources.json`: monitored repositories, feeds, and search queries.

## Editorial Standard

Every article should make the evidence boundary clear:

1. What changed or was observed.
2. Why it matters to AI memory systems.
3. Which memory layer it affects.
4. What is still uncertain.
5. Which public source or repository can be inspected.

Do not store secrets, private credentials, raw auth state, private databases, or
unredacted internal user data in this archive.
