Use this system for dense Personal AI OS memory, proof, AIGC evaluation, and
architecture tools.

## Visual Vocabulary

- Operational research workbench for architecture decisions and AI memory
  science evaluation.
- Full memory boundary is represented as a precise circle.
- Project coverage is represented as translucent circles with area-based scoring
  across a sixteen-axis AIGC memory model.
- Use off-white paper, green/teal infrastructure tones, coral warnings, gold evidence accents, plum secondary accents, and lime active-state markers.
- Use IBM Plex Serif for product and section headings; IBM Plex Sans for controls, body text, tables, and labels.
- Use gridlines, ruled panels, dossier-like evidence sections, and orbit/circle geometry to express proof and coverage.
- The evaluation model is grouped into four research layers: memory cognition,
  retrieval/grounding, agentic runtime, and assurance/governance.

## Interaction Rules

- Tabs switch views: research map, capability matrix, portfolio design, and
  governance evidence.
- Project circles are selectable controls.
- Stack planner toggles must show selected state and contribution score.
- Evidence must distinguish official support, technology signal, cases, dates,
  and strongest research capabilities.
- The context ribbon must expose derived, current values rather than decorative stats.

## Layout Rules

- Keep the app interface visible on first load.
- Keep the project detail panel persistent on desktop and inline on smaller screens.
- Avoid decorative card nesting. Panels frame functional work areas.
- Touch targets are at least 44px high.
- Use 8px panel radii, restrained shadows, and clear focus states.
- Dense tables may horizontally scroll, but navigation, search, project detail,
  and current model summaries must remain available on mobile.
